# Como contribuir

1. Trabalhe na branch individual que ja usa ou crie uma branch para a tarefa.
2. Confira o login GitHub cadastrado em `contributors.json`.
3. Coloque suas solucoes em `solutions/<sua-pasta>/`.
4. Envie a branch e abra um Pull Request para `main`.
5. O GitHub habilitara o auto-merge; a integracao ocorrera quando a verificacao obrigatoria passar.

## Regras

- Cada PR deve alterar apenas arquivos dentro da pasta associada ao autor.
- Nao envie binarios compilados, arquivos temporarios ou credenciais.
- Resolva conflitos e atualize o PR se a verificacao falhar.
- Mantenha os commits originais para preservar a autoria no historico.

## Branches existentes

Antes de abrir PR das branches antigas, reorganize as solucoes na pasta correspondente. Nao faca force-push nem rebase destrutivo sem conferir o historico.
